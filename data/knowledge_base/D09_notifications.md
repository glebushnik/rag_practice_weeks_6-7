# D09 — Notifications Service / чеки

**Статус:** действующая внутренняя заметка · **Обновлено:** 2026-07-09<br>
**Владелец:** Customer Messaging · **Канал дежурной команды:** `#oncall-messaging`

Notifications Service читает событие `billing.receipt_requested` из Event Bus и отправляет письмо с чеком на адрес плательщика. Доставка письма не меняет статус транзакции и права на платные функции. Если письмо пришло, это подтверждает работу канала уведомлений для данной транзакции, но не подтверждает доставку вебхука партнёру.

Для первичной проверки нужны ID транзакции и время оплаты. В журнале Notifications ищут принятие события, попытку отправки и ответ почтового провайдера. Статус `sent` означает передачу письма провайдеру; факт попадания в почтовый ящик пользователя по нему не устанавливают.
