# D12 — Object Storage / рабочая заметка

**Статус:** действующая · **Обновлено:** 2026-06-28<br>
**Владелец:** Storage Team · **Канал:** `#oncall-storage`

Object Storage хранит подготовленные файлы экспорта. Export Service загружает туда готовый архив и получает временную ссылку для скачивания. При недоступности хранилища загрузка нового файла или выдача ссылки может завершиться ошибкой `STO-503`. Уже запущенные экспортные задания остаются в очереди Export Service до повторной обработки.

Текстовые заявки Workspace хранятся отдельно и не зависят от Object Storage. Сбой Object Storage сам по себе не является основанием объявлять недоступным просмотр заявок.

В этой заметке нет сведений о физическом регионе хранения. По вопросам размещения данных поддержка запрашивает актуальное подтверждение у Storage Team.
