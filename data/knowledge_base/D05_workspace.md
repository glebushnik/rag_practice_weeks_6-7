# D05 — Workspace и аналитика / описание функций

**Статус:** действующее · **Обновлено:** 2026-07-08<br>
**Владелец:** Workspace Team · **Канал:** `#oncall-workspace`

Workspace хранит текстовые заявки и показывает их сотрудникам с действующей сессией. Для обычного просмотра заявок ему нужен ответ Session Service. Аналитическая панель — платная функция: перед открытием Workspace запрашивает право доступа у Entitlements Service.

Экспорт заявок запускается отдельным Export Service. Недоступность экспорта не должна мешать просмотру текстовых заявок. Workspace не решает самостоятельно, оплачен ли тариф; он использует состояние прав доступа из Entitlements Service.

Когда аналитика недоступна после оплаты, поддержка фиксирует ID аккаунта и время оплаты. Workspace показывает актуальное право, полученное от Entitlements Service; сообщение об успешном платеже в интерфейсе не заменяет эту проверку.
