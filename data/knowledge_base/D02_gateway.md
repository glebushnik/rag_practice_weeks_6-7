# D02 — API Gateway / контракты ответов

**Статус:** действующая · **Обновлено:** 2026-07-16<br>
**Владелец:** Platform · **Канал:** `#oncall-platform`

API Gateway принимает запросы приложения и направляет их во внутренние сервисы. Для закрытых маршрутов Gateway обращается к Session Service, чтобы проверить действительность сессии. Запросы на вход и смену пароля Gateway передаёт в Identity Service.

Если Session Service отвергает сессию, Gateway возвращает `AUTH-401`. Если Identity Service не отвечает во время нового входа, Gateway возвращает `IDP-503`. Ошибка `IDP-503` относится к проверке учётных данных; она не доказывает, что все уже открытые сессии завершились.

В журнале Gateway сохраняются код ответа, ID запроса и маршрут. Тело запроса и пароль в журнал не пишутся. Поддержка передаёт дежурной команде ID запроса, если по одному коду невозможно различить сбой сервиса и проблему отдельной сессии.
